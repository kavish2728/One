# Fiscal Fable CFO Mobile
Internal lightweight mobile-first workspace for managing clients, reports, tasks and document references.


## Build an APK
1. Upload these files to a new GitHub repository (keep `.github/workflows/android.yml`).
2. Open **Actions** and enable workflows if prompted.
3. Run **Build Android APK** from Actions → Run workflow.
4. Wait for the green success result and download the `Fiscal-Fable-CFO-debug-apk` artifact.

Data is currently saved locally on the device/browser using local storage. Use Profile → Export backup to save a JSON backup. There is no shared cloud sync in this starter build.
